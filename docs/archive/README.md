# Archive: pre-project documents

These are the documents that started the project. They are kept for provenance
only — the authoritative description of what was built, how it was measured and
what the numbers mean is
[`../matching-engine-project-doc.md`](../matching-engine-project-doc.md).

| File | What it is |
|---|---|
| `proposal.md` / `proposal.pdf` | the project proposal submitted for approval |
| `team-plan.md` / `team-plan.pdf` | the team-lead execution plan written before the build |

They describe the *intended* design, not the delivered one. Planned scope that
was later dropped (persistence/WAL, multi-producer queues, a 60-second stress
run) is still listed here, and none of their numbers or claims should be quoted
in place of the report's. Earlier drafts of the same two documents — a 754-line
proposal expansion and a 2 442-line private roadmap — were removed because they
duplicated these; both remain in git history.
